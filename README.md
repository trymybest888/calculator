# calculator-test

เครื่องคิดเลขบนเว็บแบบหน้าเดียว เขียนด้วย HTML, CSS และ JavaScript ล้วนในไฟล์เดียว ไม่ต้องติดตั้งอะไร

## ความสามารถ

- บวก ลบ คูณ หาร และ `%` โดยคูณหารก่อนบวกลบ
- แสดงผลลัพธ์ล่วงหน้า (`= 5`) ระหว่างพิมพ์
- ปัดเศษทศนิยมให้ เช่น `0.1 + 0.2` ได้ `0.3`
- หารด้วยศูนย์ขึ้น `Error` แล้วกดปุ่มใดก็เริ่มใหม่ได้
- ประวัติการคำนวณ: เรียงรายการใหม่สุดไว้บน คลิกรายการเพื่อนำผลลัพธ์มาคิดต่อ เก็บไว้ในเบราว์เซอร์ (localStorage) สูงสุด 50 รายการ และล้างได้
- ใช้คีย์บอร์ดได้
- โหมดมืดตามการตั้งค่าเครื่อง และแสดงผลได้บนจอมือถือ
- คำนวณด้วยตัวแยกวิเคราะห์ที่เขียนเอง ไม่ใช้ `eval()`

## วิธีใช้

เปิดไฟล์ `src/calculator.html` ในเบราว์เซอร์ได้เลย

### ปุ่มลัดคีย์บอร์ด

| ปุ่ม | การทำงาน |
|---|---|
| `0`–`9`, `.` | ใส่ตัวเลข |
| `+` `-` `*` `/` (หรือ `x`) | เครื่องหมาย |
| `%` | เปอร์เซ็นต์ |
| `Enter` หรือ `=` | คำนวณ |
| `Backspace` | ลบทีละตัว |
| `Esc`, `Delete` หรือ `C` | ล้างทั้งหมด |

## การทดสอบ

ต้องใช้ Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
node --test tests/calculator.test.js
```

ชุดทดสอบดึงโค้ดส่วน `<script id="calc-core">` ออกจากไฟล์ HTML มารันใน Node จึงทดสอบโค้ดตัวเดียวกับที่หน้าเว็บใช้ ครอบคลุมการคำนวณ ลำดับเครื่องหมาย ทศนิยม เปอร์เซ็นต์ กรณีผิดพลาด การกดปุ่ม และประวัติ

## โครงสร้างโปรเจกต์

```
src/calculator.html        หน้าเว็บเครื่องคิดเลข (UI + logic)
tests/calculator.test.js   ชุดทดสอบอัตโนมัติ (node:test)
```

ใน `calculator.html` โค้ดแบ่งเป็นสองส่วน:

- `CalcCore` (`<script id="calc-core">`): logic ล้วน ไม่แตะ DOM ได้แก่ `calculate`, `press` (รับปุ่มที่กดแล้วคืนค่า state ใหม่), `addHistory`, `preview` และ `pretty`
- สคริปต์ UI: ผูกปุ่มกดและคีย์บอร์ด แสดงผล และบันทึกประวัติลง localStorage
